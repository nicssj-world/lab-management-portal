## การเดินตรวจพื้นที่จริง

- [ ] ห้องทุกห้องและห้องซ้อนห้องตรงกับแบบต้นฉบับ (`Screenshot 2026-07-26 092955.png`)
- [ ] ห้องน้ำที่ซ้อนอยู่ในห้องหัวหน้ากลุ่มงานเทคนิคการแพทย์อยู่ในตำแหน่งถูกต้อง
- [ ] ห้องอาหารว่างสำหรับผู้บริจาคเลือดอยู่ภายในห้องรับบริจาคเลือดทั้งหมด
- [ ] ลิฟท์ 3 และลิฟท์ 4 มีขนาดเท่ากันบนผัง และตรงกับของจริง
- [ ] ขอบเขต BSL2 Enhance ตรงกับแบบต้นฉบับล่าสุด
- [ ] ชื่อห้องทุกห้องอ่านครบ ไม่มีคำหาย คำซ้ำ หรือถูกตัด ทั้งบนจอและบนกระดาษ
- [ ] เริ่มจากสำนักงาน เดินไปถึงจุดสแกนของทุกหน่วยงาน โดยหยุดที่จุดสแกนและไม่เลยเข้าพื้นที่ควบคุม
- [ ] **งานอณูชีววิทยา** นำทางไปที่จุดสแกนบนแนวกั้นข้างโซน PPE ใต้ห้องปฏิบัติการกลาง
- [ ] **งานอณูชีววิทยา ไม่ถูกนำทาง** ไปที่จุดสแกนขอบห้องปฏิบัติการภูมิคุ้มกันวิทยาคลินิก
- [ ] งานภูมิคุ้มกันวิทยาคลินิกนำทางไปที่จุดสแกนของห้องภูมิคุ้มกันฯ เอง
- [ ] งานเคมีคลินิก งานโลหิตวิทยาคลินิก และงานจุลทรรศนศาสตร์คลินิก นำทางไปที่ประตูห้องปฏิบัติการกลาง
- [ ] งานจุลชีววิทยา งานตรวจพิเศษ งานคลังเลือด และสำนักงาน นำทางถูกจุด
- [ ] หน่วยงานที่ไม่มีการจับคู่ (เช่น งานบริการผู้ป่วยนอก) แสดงข้อความให้ติดต่อสำนักงาน ไม่มีเส้นทาง
- [ ] ตำแหน่งจุดสแกนทุกจุดตรงกับอุปกรณ์และแนวกั้นจริง
- [ ] แนวกั้นควบคุมการเข้าออกปรากฏครบทุกจุดตามแบบต้นฉบับ
- [ ] **ห้องประชุมมีประตูจริงตรงตำแหน่งที่เพิ่มในระบบ** (เดิมผังไม่มีประตูห้องนี้เลย เป็นข้อบกพร่องที่แก้ในรอบนี้) — ยืนยันว่าประตูอยู่ที่ผนังฝั่งตะวันออก เชื่อมกับโถงกลาง ไม่ใช่ตำแหน่งอื่น
- [ ] **ยืนยันว่าประตูห้องประชุมไม่มีจุดสแกนนิ้วมือจริง** ตามที่แจ้ง — ถ้าพบว่ามีจุดสแกนติดตั้งเพิ่มภายหลัง ต้องแจ้งเพื่อปรับระบบเป็นจุดสแกนแบบเดียวกับปลายทางอื่น
- [ ] เดินเส้นทางจากสำนักงานไปหยุดที่ประตูห้องประชุม (ปลายทาง “หัวหน้ากลุ่มงานเทคนิคการแพทย์”) แล้วยืนยันว่าใช้งานได้จริงและปลอดภัย แม้ไม่มีจุดสแกนควบคุม

## เส้นทางหนีไฟและความปลอดภัย

> ผังหนีไฟฉบับติดผนังปัจจุบัน (ปีงบประมาณ 2569) มี layout ปีกตะวันตกต่างจากผังในระบบ — เป็นฉบับเก่า
> ที่ยังไม่ได้ปรับ **ต้องถูกถอดออกและแทนที่ด้วยฉบับที่พิมพ์จากระบบนี้หลังผ่านการตรวจรับ**

- [ ] เปิดโหมดความปลอดภัยแล้วระบบเลือกเส้นทางหลักและสำรองของสถานีนั้นให้เองโดยไม่ต้องค้นหา
- [ ] เส้นทางหลักเป็นเส้นทึบ เส้นทางสำรองเป็นเส้นประคนละแบบ และมีหัวลูกศรบอกทิศทาง
- [ ] มีป้าย “คุณอยู่ที่นี่” ที่จุดติดตั้ง และมี legend ครบทั้งเส้นทางหลัก สำรอง ทางออก ประตูล็อคถาวร ลิฟต์ต้องห้าม และถังดับเพลิง
- [ ] สถานีสำนักงาน: เส้นทางหลักและเส้นทางสำรองตรงกับป้ายจริง
- [ ] สถานีโถงหน้าห้องปฏิบัติการกลาง: เส้นทางหลักและเส้นทางสำรองตรงกับป้ายจริง
- [ ] สถานีโถงทางเดินด้านทิศใต้: เส้นทางหลักและเส้นทางสำรองตรงกับป้ายจริง
- [ ] ทางออก 3A, 3B และ 3C อยู่ในตำแหน่งถูกต้องและใช้งานได้ตามแผนฉุกเฉิน
- [ ] สัญลักษณ์ “ล็อคถาวร” ติดอยู่ที่บานประตูจริง ไม่ใช่ที่ตัวห้องควบคุมไฟฟ้า และไม่อยู่ในเส้นทางใด
- [ ] ตำแหน่งโซน PPE ถูกต้อง
- [ ] ห้องเก็บวัสดุและน้ำยาแช่เย็นถูกต้อง
- [ ] โซนคลังวัสดุรวมคลังวัสดุ คลังวัสดุและน้ำยา และห้องเก็บวัสดุและน้ำยาแช่เย็นครบ

### เส้นทางหนีไฟจากจุดสแกนแต่ละจุด (ใหม่)

ผู้มาติดต่อที่เปิดป๊อปอัพความปลอดภัยขณะยืนรอที่จุดสแกน ต้องเห็นแผนที่เริ่มจากตำแหน่งที่ยืนอยู่จริง
ไม่ใช่แผนของสำนักงานเสมอ ค่า “หลัก/สำรอง” ต่อไปนี้เป็นฉบับร่าง ให้ผู้เดินตรวจชี้ขาดจากระยะทางจริง
โดยเฉพาะจุดที่ระยะไปแต่ละทางออกใกล้เคียงกัน (ทำเครื่องหมายไว้):

- [ ] จุดสแกนห้องปฏิบัติการกลาง — เดินตรวจ 3B (หลัก) และ 3A (สำรอง)
- [ ] จุดสแกนห้องปฏิบัติการภูมิคุ้มกันวิทยาคลินิก — เดินตรวจ 3A (หลัก) และ 3B (สำรอง)
- [ ] จุดสแกนงานอณูชีววิทยา (แนวกั้นข้างโซน PPE) — เดินตรวจ 3A (หลัก) และ 3B (สำรอง)
- [ ] จุดสแกนงานจุลชีววิทยา — เดินตรวจ 3B (หลัก) และ 3A (สำรอง)
- [ ] **จุดสแกนงานตรวจพิเศษ** — เดินตรวจ 3C (หลัก) และ 3B (สำรอง) ⚠ ระยะไปแต่ละทางใกล้เคียงกันมาก ต้องยืนยันด้วยการจับเวลาเดินจริง
- [ ] **จุดสแกนงานคลังเลือด** — เดินตรวจ 3C (หลัก) และ 3B (สำรอง) ⚠ ระยะไปแต่ละทางใกล้เคียงกันมาก ต้องยืนยันด้วยการจับเวลาเดินจริง
- [ ] เปิดป๊อปอัพความปลอดภัยของผู้มาติดต่อ แล้วยืนยันว่าจุดเริ่มต้นตรงกับหน่วยงานปลายทางในบัตร ไม่ใช่สำนักงานเสมอไป
- [ ] ทดสอบปุ่มสลับกลับไปแผนของสำนักงานในป๊อปอัพ ใช้งานได้ถูกต้อง
- [ ] **จุดติดตั้งแผนที่ห้องประชุม (ใหม่)** — เดินตรวจ 3C (หลัก) และ 3A (สำรอง) จากประตูห้องประชุม

### ปลายทาง "หัวหน้ากลุ่มงานเทคนิคการแพทย์" — ข้อยกเว้นด้านความปลอดภัยเดียวที่อนุมัติแล้ว (ใหม่)

ทุกปลายทางผู้มาติดต่ออื่นในระบบต้องจบที่จุดสแกนนิ้วมือเสมอ ปลายทางนี้เป็น**ข้อยกเว้นเดียว**
ที่อนุมัติแล้วเพราะประตูห้องประชุมไม่มีจุดสแกนจริง (`APPROVED_NON_FINGERPRINT_VISITOR_DESTINATIONS`
ใน `lib/lab-map/validate.ts`) ต้องตรวจยืนยันเป็นพิเศษก่อนเผยแพร่:

- [ ] ยืนยันกับผู้รับผิดชอบความปลอดภัยอีกครั้งว่ายอมรับข้อยกเว้นนี้ได้จริง (ไม่มีจุดสแกน แต่อนุญาตให้เป็นปลายทางผู้มาติดต่อ)
- [ ] ผู้มาติดต่อที่เลือก "หัวหน้ากลุ่มงานเทคนิคการแพทย์" ในฟอร์มลงทะเบียน ได้รับคำแนะนำที่ชัดเจนว่าให้หยุดที่ประตูและรอเจ้าหน้าที่ ห้ามเข้าเอง
- [ ] มีเจ้าหน้าที่ประจำพร้อมมารับที่ประตูห้องประชุมได้จริงเมื่อมีผู้มาติดต่อ (ไม่มีระบบแจ้งเตือนอัตโนมัติ — เป็นกระบวนการที่ต้องพึ่งคน)

### ถังดับเพลิงและจุดรวมพล (ใหม่ — พิกัดยังไม่ยืนยัน)

พิกัดถังดับเพลิงทั้ง 11 จุดแปลงมาจากผังฉบับติดผนังด้วยการแปลงพิกัดเชิงเส้นจากป้ายทางออก
ไม่ใช่การวัดหน้างาน **ทุกจุดต้องเดินยืนยันตำแหน่งจริงและปรับพิกัดใน `lib/lab-map/safety-assets.ts`
ให้ตรง แล้วตั้ง `verified: true` ทีละจุด** — ระบบจะเผยแพร่เป็นฉบับใช้งานจริงไม่ได้จนกว่าจะยืนยันครบ

- [ ] ถังดับเพลิง 1 — ผนังโถงเหนือ ใต้ BSL2 Enhance
- [ ] ถังดับเพลิง 2 — โถงเหนือ ฝั่งตะวันตก
- [ ] ถังดับเพลิง 3 — โถงเหนือ ช่วงกลาง
- [ ] **ถังดับเพลิง 4** — ฝั่งตะวันตก ใต้แนวโถงเหนือ ⚠ อยู่ในปีกที่ผังฉบับเก่าต่างจากผังปัจจุบันมากที่สุด ให้ตรวจเป็นลำดับแรก
- [ ] ถังดับเพลิง 5 — แกนกลาง ตอนบน
- [ ] ถังดับเพลิง 6 — โถงระหว่างบล็อกกลางกับปีกตะวันออก
- [ ] ถังดับเพลิง 7 — แกนกลาง ตอนกลาง ข้างห้องปฏิบัติการตรวจพิเศษ
- [ ] ถังดับเพลิง 8 — มุมโถงหน้าสำนักงานกลุ่มงานฯ ตรงช่องเปิดข้างห้องเตรียมเลือด
- [ ] ถังดับเพลิง 9 — แกนกลาง รอยต่อระหว่างห้องแยกส่วนประกอบของเลือดกับห้องเตรียมเลือด (จุดที่ตกหล่นในการถอดข้อมูลรอบแรก)
- [ ] ถังดับเพลิง 10 — ปีกตะวันออก ในห้องรับบริจาคเลือด ข้างห้องอาหารว่าง
- [ ] ถังดับเพลิง 11 — โถงใต้ ก่อนถึงทางออก 3C
- [ ] ยืนยันจุดรวมพล “พื้นที่หน้าอาคารอำนวยการ (ด้านหน้าหอพระ)” ยังใช้ได้จริง หรือระบุจุดรวมพลแยกต่อทางออกหากจำเป็น
- [ ] ป้ายห้ามใช้ลิฟต์ขณะเกิดเหตุติดอยู่ที่ลิฟต์ 1–4 จริง และตรงกับที่แผนที่แสดง

## การควบคุมการติดเชื้อและข้อมูลเปิดเผย

- [ ] สีแดง/เขียว/เหลืองตรงกับพื้นที่ติดเชื้อ/สะอาด/เสี่ยงที่ผู้รับผิดชอบอนุมัติ
- [ ] สีทุกชนิดมีลวดลายหรือข้อความกำกับ ไม่อาศัยสีเพียงอย่างเดียว
- [ ] BSL2 Enhance และ PCR อยู่ภายใต้งานจุลชีววิทยาในฉบับภายใน
- [ ] แผนที่ในป๊อปอัพของผู้มาติดต่อไม่แสดงชั้นการติดเชื้อ
- [ ] แผนที่ไม่มีข้อมูลหรือสถานะทะเบียนเครื่องมือ และไม่มีข้อมูลบุคลากรอีกต่อไป

## สิ่งพิมพ์และอุปกรณ์จริง

- [ ] หน้าส่งออก `/staff/lab-map/print` แสดงแผนที่ปกติ ไม่ใช่สี่เหลี่ยมดำ ทั้งตัวอย่างบนจอและไฟล์ที่ดาวน์โหลด
- [ ] จุดติดตั้งในหน้าส่งออกแสดงชื่อไทย ไม่ใช่รหัสดิบ
- [ ] จุดสแกนนิ้วมือ (สถานีชนิด checkpoint) ไม่ปรากฏเป็นตัวเลือกจุดติดตั้งในหน้าส่งออก — ใช้สำหรับป๊อปอัพดิจิทัลเท่านั้น ไม่ใช่ป้ายพิมพ์แยก
- [ ] A3 เส้นทางหนีไฟอ่านชื่อห้อง สัญลักษณ์ และเส้นทางได้จากระยะติดตั้งจริง
- [ ] A4 เส้นทางหนีไฟอ่านได้ที่ 100% โดยไม่มีข้อความ/QR/เส้นทางถูกตัด
- [ ] A3/A4 ควบคุมการติดเชื้อแสดงลวดลายและ legend ครบ
- [ ] A3/A4 นำทางผู้มาติดต่อใช้เรขาคณิตชุดเดียวกับฝั่งเจ้าหน้าที่ แต่ไม่มีชั้นการติดเชื้อ
- [ ] PNG ทุกชนิดมีความละเอียดเพียงพอและอัตราส่วนไม่ผิดรูป
- [ ] QR เปิดเวอร์ชันเว็บปัจจุบันบนโทรศัพท์จริง (เส้นทางสาธารณะ `/lab-map/...` ถูกถอดออกแล้ว ต้องได้ 404)
- [ ] ลงทะเบียนเข้า เปิดป๊อปอัพแผนที่ ปิดป๊อปอัพ แล้วกดบันทึกออกจากหน้าเดิมบนโทรศัพท์จริงสำเร็จ
- [ ] ป๊อปอัพปิดด้วยปุ่มปิดและปุ่ม Escape ได้ และโฟกัสกลับไปที่ปุ่มที่กดเปิด
- [ ] เมื่อไม่มีไฟฟ้าหรือเครือข่าย ผู้ใช้งานยังปฏิบัติตามป้ายฉบับอนุมัติที่ติดตั้งได้
