# ป้ายชื่อห้องบนแผนที่หลังเปลี่ยนชื่อ

## ปัญหา

การแก้ชื่อพื้นที่บันทึก `equipment_areas.name_th` และแสดงชื่อใหม่ในแผงรายละเอียดได้แล้ว แต่ป้ายใน SVG ยังอ่าน `label.lines` คงที่จาก `manifest.ts` จึงแสดงชื่อเดิมต่อไป

## พฤติกรรมที่ต้องการ

- พื้นที่ที่มีชื่อ override จากฐานข้อมูลต้องแสดงชื่อ override บนแผนที่หลัง `router.refresh()`
- ตัดคำภาษาไทยอัตโนมัติให้พอดีกับความกว้างพื้นที่
- จำกัดจำนวนบรรทัดตามความสูงพื้นที่ และลดขนาดตัวอักษรเมื่อจำเป็นโดยมีขนาดต่ำสุดที่อ่านได้
- ใช้พิกัดกึ่งกลางป้ายเดิม เพื่อไม่เปลี่ยนตำแหน่งหรือรูปทรงของพื้นที่
- พื้นที่ที่ไม่ได้เปลี่ยนชื่อต้องคง `label.lines` และ `fontSize` จาก manifest เหมือนเดิมทุกประการ
- พื้นที่ที่ manifest ตั้งใจไม่แสดงป้าย (`label: null`) ต้องยังไม่สร้างป้าย แม้มีชื่อ override

## การออกแบบ

เพิ่ม pure helper สำหรับสร้างบรรทัดป้ายจากข้อความภาษาไทย ความกว้าง/ความสูงพื้นที่ และขนาดตัวอักษรตั้งต้น โดยใช้ `Intl.Segmenter` แบ่งคำ และมีการแบ่งตาม grapheme เป็น fallback เมื่อคำหนึ่งยาวกว่าความกว้างที่รองรับ

`buildEquipmentMapDTO` จะเรียก helper เฉพาะเมื่อ:

1. มี override ของพื้นที่
2. ชื่อ override ต่างจากชื่อใน manifest
3. พื้นที่เดิมมี label

ผลลัพธ์จะเปลี่ยนเฉพาะ `label.lines` และอาจลด `label.fontSize`; ค่า `x`, `y`, รูปทรง สี ผนัง และประตูไม่เปลี่ยน

## การทดสอบ

- ชื่อ override ถูกตัดบรรทัดและรวมกลับมาเป็นชื่อใหม่ ไม่เหลือชื่อ manifest เดิม
- ชื่อยาวไม่เกินจำนวนบรรทัดที่ความสูงพื้นที่รองรับ และ font size ไม่ต่ำกว่าค่าขั้นต่ำ
- พื้นที่ไม่มี override คืน label เดิมแบบเท่ากันทุกค่า
- พื้นที่ที่ไม่มี label ยังคง `label: null`
- รันชุดทดสอบ equipment-map, TypeScript และ `git diff --check`
