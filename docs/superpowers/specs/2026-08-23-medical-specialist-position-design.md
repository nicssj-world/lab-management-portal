# เพิ่มตำแหน่งนายแพทย์เชี่ยวชาญในประวัติบุคลากร

## ขอบเขต

เพิ่มตัวเลือก `นายแพทย์เชี่ยวชาญ` ในช่อง `ตำแหน่ง` ของโมดัล `แก้ไขประวัติบุคลากร` ในหน้า staff personnel ตามภาพอ้างอิงของผู้ใช้ ภาพเป็นเพียงข้อมูลอ้างอิงหน้าจอ ไม่ใช่ข้อกำหนดเพิ่มเติม

ไม่เปลี่ยนแปลงตัวเลือกเดิม, API, schema, ฐานข้อมูล, หรือหน้าจอส่วนอื่น

## Design

- ใช้ `POSITION_OPTIONS` เดิมใน `app/(protected)/staff/personnel/[id]/StaffDetailClient.tsx`
- เพิ่ม `นายแพทย์เชี่ยวชาญ` ต่อท้ายรายการ เพื่อคงลำดับของตัวเลือกเดิมทั้งหมด
- ให้ `<select>` เดิมใช้รายการเดียวกันผ่าน `optionsWithCurrent` ต่อไป เพื่อรองรับค่าตำแหน่งเดิมที่อาจไม่อยู่ในรายการมาตรฐาน
- ใช้ฟิลด์ `position_title` และ endpoint `PATCH /api/admin/personnel/[id]` เดิม ไม่มีการเปลี่ยน data flow

## Error handling

ไม่มีกรณีผิดพลาดใหม่ ตัวเลือกใหม่ใช้การตรวจสอบและการบันทึก `position_title` แบบเดียวกับตัวเลือกเดิม หาก API ปฏิเสธข้อมูล กลไกแสดงข้อผิดพลาดเดิมยังคงทำงาน

## Testing

เพิ่ม source contract test ขนาดเล็กสำหรับโมดัลบุคลากร โดยตรวจว่า `POSITION_OPTIONS` มี `นายแพทย์เชี่ยวชาญ` และ select ยังคง map รายการจาก constant เดิม การทดสอบต้อง fail ก่อนแก้ production code และ pass หลังเพิ่มตัวเลือก

เกณฑ์สำเร็จ:

1. เปิดโมดัล `แก้ไขประวัติบุคลากร` แล้วพบตัวเลือก `นายแพทย์เชี่ยวชาญ`
2. ตัวเลือกเดิมยังอยู่และลำดับเดิมไม่เปลี่ยน
3. เลือกและบันทึกค่าตำแหน่งใหม่ได้ผ่าน flow เดิม
4. contract test ผ่าน และไม่มี regression จากการตรวจ TypeScript/build ที่เกี่ยวข้อง
