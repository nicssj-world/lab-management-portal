# ตัวกรองรายการเครื่องมือที่ยังไม่กำหนดตำแหน่ง

## เป้าหมาย

ย้ายตัวกรองแผนกและ Classification ออกจากแถบรายงานด้านขวาไปเป็นแถบแนวนอนเหนือพื้นที่แผนที่ พร้อมเพิ่มตัวกรอง “ต้องการสอบเทียบ” สำหรับรายการเครื่องมือที่ยังไม่กำหนดตำแหน่งเท่านั้น

แผนผังยังคงมีจุดประสงค์เดิม คือใช้วางแผน PM/CAL โดยเดินตรวจทีละพื้นที่ เครื่องมือที่แสดงเป็นหมุดบนแผนที่จึงไม่ถูกกรองด้วยปุ่มใหม่นี้

## การทำงานของหน้าจอ

- แถบตัวกรองรายการจะแสดงเฉพาะเมื่อเปิดรายงาน “ยังไม่กำหนดตำแหน่ง”
- แถบอยู่ระหว่างตัวกรองแผนที่เดิมกับพื้นที่แผนที่/รายงาน
- ภายในแถบประกอบด้วยตัวเลือก “แผนก”, ตัวเลือก “Classification” และปุ่มสลับ “ต้องการสอบเทียบ”
- ปุ่ม “ต้องการสอบเทียบ” ใช้ `needs_calibration = true` เป็นเงื่อนไขและแสดงสถานะเปิด/ปิดอย่างชัดเจนด้วย `aria-pressed`
- ตัวกรองทั้งสามใช้ร่วมกันแบบ AND
- เมื่อเปลี่ยนตัวกรอง ให้กลับไปหน้า 1 และคำนวณจำนวนรายการกับจำนวนหน้าใหม่
- รายงานด้านขวาเหลือหัวรายงาน ปุ่มกลับ การแบ่งหน้า และรายการครั้งละ 5 เครื่อง
- เมื่อปิดรายงาน แถบตัวกรองรายการจะหายไป โดยตัวกรองหมุดบนแผนที่เดิมไม่เปลี่ยนแปลง

## โครงสร้างข้อมูลและคอมโพเนนต์

- เพิ่ม `needsCalibration` ใน `EquipmentUnplacedDTO` และส่งค่าจาก `equipment.needs_calibration` ผ่านตัวสร้างข้อมูลแผนที่
- ขยายฟังก์ชันกรองแบบ pure function ให้รับเงื่อนไข `calibrationOnly`
- ย้าย state ของตัวกรองรายการขึ้นไปที่ `EquipmentMapClient` เพื่อให้แถบด้านบนและรายงานด้านขวาใช้ข้อมูลชุดเดียวกัน
- สร้างคอมโพเนนต์แถบตัวกรองรายการแยกจาก `PlacementPanel`; `PlacementPanel` รับรายการที่กรองแล้วและดูแลเฉพาะ pagination/การแสดงรายการ

## กรณีว่างและการเข้าถึง

- ถ้าตัวกรองไม่พบรายการ ให้แสดงสถานะว่างพร้อมปุ่มล้างตัวกรอง
- ปุ่มล้างตัวกรองคืนค่าแผนกและ Classification เป็นทั้งหมด และปิด “ต้องการสอบเทียบ”
- ปุ่มสลับต้องใช้งานได้ด้วยคีย์บอร์ดและมีชื่อที่สื่อความหมายโดยไม่พึ่งสี

## การทดสอบ

- ทดสอบว่า `calibrationOnly` เลือกเฉพาะ `needsCalibration = true` และทำงานร่วมกับแผนก/Classification
- ทดสอบว่าการแบ่งหน้ายังคงแสดงครั้งละ 5 รายการหลังกรอง
- ทดสอบสัญญา UI ว่าแถบตัวกรองอยู่เหนือ workspace เฉพาะตอนเปิดรายงาน และไม่มีตัวกรองซ้ำในแถบรายงานด้านขวา
- รัน TypeScript, ชุดทดสอบ equipment-map ทั้งหมด และตรวจหน้าเว็บจริง
